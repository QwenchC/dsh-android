# DSH for Android 0.1.4

本次更新汇总 0.1.0 之后的可靠性、工具审批、权限与 WebView 加固，以及 Android 8 兼容性改进。

## 下载与安装

- `DSH-Android-0.1.4-debug.apk`：Android 8.0 / API 26 起，包含 arm64-v8a 与 x86_64。
- 版本：**0.1.4 / versionCode 6**，调试签名。签名证书与此前发布的 0.1.0 一致，可覆盖安装。
- APK 大小：**115,988,599 字节**。
- 下载后可使用 `SHA256SUMS.txt` 核对文件；源码由本 Release 对应的 Git 标签提供。

```text
APK SHA256 ad2a972cca00d821fc6542066db8bde6fa4b50777dee489ffe3203e81e6d8574
```

## 更新内容

- 修复启动、停止和重复启动之间的竞争；启动解压可取消，旧进程退出前阻止新运行和项目迁移。
- 项目迁移校验实际文件内容，发现冲突时保留原文件并报告失败，完成后才切换工作目录。
- 默认要求工具执行确认，提供“允许一次”和“拒绝”；自主执行需要在原生菜单明确开启并重新启动 Harness。
- WebView 原生桥限制到当前运行的精确回环来源和主框架，限制外部导航与资源访问，关闭文件 URL 访问和混合内容。
- 修复文件上传的多选、重复 URI、取消、页面重建及迟到结果归属问题。
- 移除 Android 平台 API 弃用调用，更新系统栏及键盘边距处理。
- 手机宽度下设置页面改为顶部横向导航，设置项使用完整宽度。
- 增加单元、策略、设备兼容性和真实模型审批测试；截图等待画面稳定后再采集。
- 固定构建工具版本并启用严格警告检查；当前 AGP 为 **9.5.0-alpha09 预览版**。

## 验证结果

- Java 单元测试 **25 通过、1 项 Windows 符号链接测试跳过**；相关符号链接行为另有 Android 设备测试覆盖。
- 实际 Harness 策略组合测试 **10 通过**；lint **0 问题**，严格编译与 Debug/unsigned Release/test APK 构建通过。
- Android 8.0 / API 26 **x86_64**、Chrome/WebView **119.0.6045.194**：**15 组平台兼容性检查、4 组生产界面检查、3 种真实 DeepSeek 审批交互通过**。
- 真实模型验证覆盖允许一次后产生文件、拒绝后不产生文件，以及待审批时通过原生菜单停止后不产生文件。停止进程不等于已写入一条配对的“取消审批”记录。
- Android 16 / API 36 与 Android 17 / API 37 的 x86_64 模拟器：本版运行时和安全回归各 **11 项通过**。
- 最终 Android 8 界面验收留存 **11 张截图**；发布前重新检查 APK 签名及 SHA-256。

完整证据范围和日期见 [验证记录](https://github.com/QwenchC/dsh-android/blob/v0.1.4/docs/verification.md)；行为说明见 [Android 加固文档](https://github.com/QwenchC/dsh-android/blob/v0.1.4/docs/android-hardening.md)。Release 附带 `verification-summary.json`。

## 兼容性范围

- **Android 8 ARM64 运行时与 ARM64 真机尚未验收**。ARM64 模拟器尝试被引擎启动、音频服务和分区挂载故障阻断；APK 包含 ARM64 原生文件，不代表这些设备已通过运行测试。
- Android 8 的上述结果仅适用于记录中的 x86_64/WebView 组合。系统镜像自带 WebView 69 无法解析 Harness 页面；测试所用 119 是冻结的兼容性环境，不是当前受安全支持的浏览器，也不随本 APK 分发。
- 命令使用应用本身的 Android 权限执行；工具审批不提供额外的系统级命令沙箱。
- 图片附件、Office 转换仍不可用；API 27–29、长时间后台/电池表现、长会话压缩与完整无障碍验收尚未完成。会话紧凑显示沿用 Harness 现有功能，长工作链自动折叠尚未专项验收。
